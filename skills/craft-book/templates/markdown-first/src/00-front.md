# About this book {.unnumbered}

This is a deliberately short learning text, not an encyclopaedia. It assumes
PREREQUISITES; Appendix A refreshes the parts most readers have half-forgotten.
The text states the conditions behind its central identities and points to
primary references when a complete proof would defeat the purpose of a compact guide.

The source is designed to be revised. If you find an error, record the smallest
counterexample you can.

# Reader's contract {.unnumbered}

Five questions persist across every method in this subject:

1. What quantity is the objective averaging?
2. Under which distribution?
3. Which target is estimated, and does it bootstrap?
4. Where do approximation and distribution shift enter?
5. What evidence would distinguish learning from a misleading metric?
